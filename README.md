# Med Daddy v8.4.0 — PCT II Environmental Emergencies

This release adds the Patient Care & Theory II **Environmental Emergencies** unit while preserving every existing Med Daddy module.

## New in this release

- 579 original four-option questions
- 174 directly mapped course concepts
- Balanced answer key: A 145 / B 145 / C 145 / D 144
- 12 detailed learning guides
- 50-question exam-length mock, 100-question challenge and complete-bank mode
- Focused Burns; Heat & Cold; Water, Diving & Altitude; and Toxicology & HazMat drills
- Direct coverage of every term and emphasis point in the supplied study guide
- Coverage and difficulty shaped by the supplied 120-question highlighted mock
- Moodle sample used only as a low-weight coverage check
- Current-practice clarification using Ontario BLS PCS 3.4 and ALS PCS 5.4
- Explicit corrections for unsafe or oversimplified mock answers

## Deployment

Upload `index.html` and `.nojekyll` directly to the root of a GitHub repository. In **Settings → Pages**, publish from the `main` branch and `/(root)`.

This app is an educational study aid and does not replace current Ontario standards, medical directives, local policy, base-hospital direction, poison-centre/HazMat guidance or clinical judgment.
